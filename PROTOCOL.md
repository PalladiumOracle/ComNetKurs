# Протокол обмена кадрами
## 1. Назначение
Протокол определяет формат кадра, который передаётся между узлами оверлейной сети поверх TCP. Кадр состоит из фиксированного заголовка и переменного payload.

## 2. Раскладка заголовка (24 байта)

| offset | size | field            | тип      | описание                              |
|--------|------|------------------|----------|---------------------------------------|
| 0      | 1    | `version`        | uint8    | версия протокола (сейчас 1)           |
| 1      | 1    | `type`           | uint8    | тип кадра                             |
| 2      | 2    | `flags`          | uint16   | флаги                                 |
| 4      | 8    | `request_id`     | uint64   | идентификатор запроса                 |
| 12     | 4    | `payload_length` | uint32   | длина payload в байтах                |
| 16     | 8    | `reserved`       | uint64   | зарезервировано (сейчас 0)            |

## 3. Типы кадров (поле `type`)

| значение | константа              | назначение                        |
|----------|------------------------|-----------------------------------|
| 1        | `FRAME_TYPE_HELLO`     | приветствие                       |
| 2        | `FRAME_TYPE_HELLO_ACK` | ответ на приветствие              |
| 3        | `FRAME_TYPE_BYE`       | штатное завершение                |
| 4        | `FRAME_TYPE_BYE_ACK`   | подтверждение завершения          |
| 16       | `FRAME_TYPE_DATA`      | прикладные данные                 |

## 4. Ограничения
1) version - сейчас всегда 1. Кадр с другой версией будет отклоняться
2) payload_length ≤ MAX_FRAME_PAYLOAD. Кадр с payload_length > max_frame_payload отклоняется до выделения памяти.
3) request_id - уникален в пределах сессии. Ответ содержит тот же request_id, что и запрос.

## 5. Пример
Кадр "HELLO" с request_id = 42, payload = b"Hello from node2"
offset bytes (hex) расшифровка
0 01 version = 1
1 01 type = FRAME_TYPE_HELLO
2-3 00 00 flags = 0
4-11 00 00 00 00 00 00 00 2A request_id = 42
12-15 00 00 00 10 payload_length = 16
16-23 00 00 00 00 00 00 00 00 reserved = 0
24-39 48 65 6C 6C 6F ... payload = "Hello from node2"
